# Pastas do menu de apps do GNOME, recriadas do zero pelo módulo "apps_gnome"
# do post-install.
#
# O nome entre colchetes é o nome da pasta (e vira o ID dela no dconf).
# "diretorio" aponta um arquivo .directory padrão (de /usr/share/desktop-directories,
# instalados pelo gnome-shell e pelo gnome-menus): se ele existir na máquina,
# a pasta usa o nome traduzido para o idioma do sistema (ex.: Game.directory ->
# "Games" em inglês, "Jogos" em português); senão, usa o nome entre colchetes.
#
# Cada pasta junta os apps cujo .desktop declare alguma das "categorias"
# (categorias do freedesktop.org: Development, Game, Office...). Assim a
# organização vale em qualquer distro e pega também os apps instalados
# depois. "apps" coloca na pasta apps específicos (IDs do .desktop) que
# declaram categorias ruins ou nenhuma.
#
# A ORDEM IMPORTA: um app que se encaixe em mais de uma pasta fica só na
# primeira delas (ex.: a Steam declara Network e Game, e vai para Games),
# e é excluído das outras. Apps sem nenhuma categoria daqui ficam soltos no
# menu. Pastas sem nenhum app instalado não aparecem.
