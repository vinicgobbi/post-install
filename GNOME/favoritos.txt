# Apps fixados na barra de favoritos (dash/dock; no KDE, os apps fixados do
# painel do Plasma), aplicados pelo módulo "apps_gnome" do post-install, na
# ordem abaixo.
#
# Um app por linha (ID do .desktop). Alternativas separadas por "|": entra o
# primeiro que estiver instalado (o terminal e a loja mudam de uma distro para
# outra). Apps que não existirem na máquina são pulados.
#
# Para atualizar a partir de uma máquina já configurada:
#   gsettings get org.gnome.shell favorite-apps   (no Mint: org.cinnamon favorite-apps)
#   (no KDE: launchers= do org.kde.plasma.icontasks em
#   ~/.config/plasma-org.kde.plasma.desktop-appletsrc)
