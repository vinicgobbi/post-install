# Extensões do GNOME aplicadas pelo módulo "extensoes_gnome" do post-install.
# Uma por linha (UUID). As que não vêm instaladas com o sistema são baixadas
# do extensions.gnome.org na versão compatível com o GNOME Shell da máquina.
# UUID seguido de uma URL git = instalada do repositório (git clone +
# make install), para extensões que não estão no extensions.gnome.org.
# Depois da URL, opcionalmente, o commit (ou tag) a instalar — recomendado,
# para uma mudança na branch principal não chegar sozinha às instalações.
# Prefixo "-" = manter desativada (ex.: extensões que vêm com o Ubuntu).
#
# A mesma lista serve ao Ubuntu e ao Fedora:
# - "a | b": equivalentes. A primeira que vier com o sistema é ativada; se
#   nenhuma vier, a ÚLTIMA da linha é baixada do extensions.gnome.org (ex.: a
#   dock do Ubuntu e, no Fedora, o Dash to Dock, que usa as mesmas
#   preferências de extensoes.dconf);
# - "uuid sistema": só é ativada se vier com o sistema; nunca é baixada.
